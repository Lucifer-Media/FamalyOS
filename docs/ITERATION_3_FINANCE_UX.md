# Family OS — Итерация 3 (доработки раздела «Финансы»)

Продолжение работы поверх Итерации 1-2. Ничего из существующей функциональности
(импорт выписок, ручной ввод операций, сверка с ЖКХ, аналитика, дашборд) не
менялось по логике — только добавлено новое. Миграций БД в этой итерации
**нет** — все новые данные хранятся как обычные JSON-атрибуты существующих
сущностей (`bank`, `bank_account`, `budget`), в духе принципа проекта «общая
оболочка Entity + специализированная структура в attributes».

## Что добавлено

### 1-2. Архивирование и редактирование банковских счетов
Оказалось, что общий backend (`EntitiesController`/`EntitiesService`) уже умел
архивировать/разархивировать/редактировать **любую** сущность — `PATCH
/entities/:id`, `PATCH /entities/:id/archive`, `/unarchive`. Не хватало только
интерфейса для счетов:
- `/finance` (список счетов) — переключатель «Показать архивные», кнопка
  архивирования на карточке счёта.
- `/finance/accounts/[id]` — новая карточка «Реквизиты и информация о счёте»
  с полным редактированием через `DynamicEntityForm` (банк, номер счёта,
  привязанная карта, ставка, кредитный лимит, даты открытия/закрытия), кнопки
  «Архивировать»/«Восстановить» и «Версии» (история изменений). Раздел
  операций и импорт выписок не тронуты.

### 3. Визуальная принадлежность счетов к банкам
`apps/web/src/lib/bank-branding.ts` — определяет цвет и инициалы банка по
приоритету: свой цвет счёта (`brandColorOverride`) → цвет банка из
справочника (`bank.brandColor`, новое поле) → эвристика по названию для
известных российских банков (Т-Банк, Альфа-Банк, Сбер, ВТБ, Газпромбанк,
Райффайзен, Открытие, Росбанк, Совкомбанк, Озон Банк, Яндекс Банк, Почта
Банк, МТС Банк) → детерминированный цвет по хэшу названия (стабилен между
загрузками, но не «настоящий» фирменный, если банк не из списка и не задан
свой цвет). Используется компонентом `BankAvatar` на карточках счетов и в
шапке страницы счёта.

### 4 и 6. Редактирование и архивирование бюджетов
- `/finance/budgets` — переключатель «Показать архивные», архивирование
  прямо с карточки, переход на новую страницу `/finance/budgets/[id]`.
- `/finance/budgets/[id]` (новая страница) — полное редактирование через
  `DynamicEntityForm`, «Архивировать»/«Восстановить», история версий — по
  тому же шаблону, что и карточка документа/счёта.

### 5. Разбивка бюджета по периодам
На странице `/finance/budgets/[id]` — блок «Разбивка бюджета по периодам»:
выбор типа разбивки (по годам / по месяцам / по неделям), добавление строк
«период → плановая сумма», факт по каждому периоду (на основе тех же правил
сопоставления операций, что и общий статус бюджета). Хранится в
`budget.attributes.periodAllocations` (массив `{period, plannedAmount}`) и
`periodBreakdownType`.

Логика периодов вынесена в файл без зависимости от Prisma —
`apps/api/src/finance/budget-periods.ts` (по образцу `reconciliation.ts`),
чтобы её можно было тестировать в изоляции. 13 юнит-тестов —
`apps/api/src/finance/__tests__/budget-periods.spec.ts`.

Новый эндпоинт: `GET /finance/budgets/:id/periods` — факт/план по каждому
периоду. Логика сопоставления операций с бюджетом (была внутри
`getBudgetStatus`) вынесена в приватный метод `matchBudgetTransactions`,
переиспользуется обоими эндпоинтами — поведение `getBudgetStatus` не
изменилось (проверено существующими тестами `finance-analytics.service.spec.ts`,
все 128 тестов бэкенда проходят).

### 7. Категории и подкатегории теперь достижимы из «Финансов»
- Новый общий компонент `FinanceSubNav` (Счета / Дашборд / Бюджеты /
  Категории / Аналитика) подключён на все страницы раздела «Финансы».
- Новая страница `/finance/categories` — дерево категорий/подкатегорий
  (`financial_category`, иерархия через `parentCategoryId`), с быстрым
  созданием и переходом в существующую карточку `/documents/financial_category/[id]`
  для редактирования/архивирования конкретной категории.
- Заодно кнопки «Архивировать»/«Восстановить» добавлены и в общую карточку
  сущности `/documents/[type]/[id]` — раньше архивирование не было доступно
  для *ни одного* типа через эту страницу (только через API), теперь это
  системное дополнение работает для всех типов, не только финансовых.

### 8. Сверка с famfi.app
Изучены присланные скриншоты famfi.app (тёмная тема, разделы Обзор /
Транзакции / Бюджет / Календарь / Категории / Счета / Аналитика / Портфель,
цветные аватары счетов по банку/участнику, прогресс-бары бюджетов,
финансовый календарь с прогнозом на конец месяца). Часть паттернов уже
принята в этой итерации (цветные аватары банков, прогресс-бары бюджетов,
удобная суб-навигация, дерево категорий). Полный визуальный паритет — единый
финансовый календарь с прогнозом остатка, отдельная лента «Транзакции» на
уровне всего раздела (не только внутри счёта), раздел «Портфель» (кредиты,
вклады, Net Worth) — это отдельный по объёму фронт работ, в этой итерации
сознательно не делался «между делом», см. `TECH_DEBT.md`.
