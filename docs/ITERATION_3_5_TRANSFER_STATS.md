# Family OS — Итерация 3.5 (статистика переводов между счетами)

Небольшое продолжение после Итерации 3.4 (переводы теперь можно создавать
явно с выбором «откуда»/«куда» на `/finance/transactions`). Закрывает
пункт «Статистика переводов между счетами» из расширенной аналитики
(`TECH_DEBT.md`, пункт 40).

## Что сделано

`FinanceAnalyticsService.getTransferSummary` — агрегирует уже связанные
пары переводов (`transactionType: 'TRANSFER'` + взаимный
`relatedTransactionId`, которые линкуются либо автоматически при импорте
выписки, либо явно через форму перевода из Итерации 3.4) за период:
- общий объём переведённых денег и количество переводов;
- разбивка по парам счетов («откуда → куда», сумма, количество).

Каждая пара считается **один раз** (не дважды — по расходной и приходной
стороне), направление определяется по знаку суммы.

Новый эндпоинт: `GET /finance/analytics/transfers?startDate&endDate`.
Новая карточка «Переводы между счетами» на `/finance/analytics`, между
блоком «По участникам» и тепловой картой.

## Тесты
4 новых теста (`transfer-summary.spec.ts`): правильный подсчёт пары один
раз, игнорирование несвязанных TRANSFER-операций (без пары), игнорирование
обычных операций, фильтрация по датам + суммирование нескольких переводов
между одной и той же парой счетов. Backend: **169/169** тестов (было 165).
